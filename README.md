## Latest Development

CodeSense AI is an AI-powered developer intelligence platform designed to analyze software repositories, detect potential code-quality issues, and provide intelligent developer assistance.

### Current Features
- Python repository scanning
- Function and class detection
- Lines of code analysis
- Cyclomatic complexity analysis
- Function length analysis
- Function argument analysis
- Repository-level metrics
- FastAPI backend
